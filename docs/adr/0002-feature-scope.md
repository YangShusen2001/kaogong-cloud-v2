# ADR 0002：功能范围（历史版本）

- **日期**：2026-08-13
- **状态**：已被当前产品需求取代

## 背景

原项目有 24 个 API 端点，覆盖登录/注册、收藏、划线 AI 解释、每日一练、考点卡片、学习统计、后台管理、邮件、订阅、自定义文章、地区偏好等。对一个"个人学习工具"，多用户体系、后台、邮件是重活且收益低。

## 历史决策

### 保留（重构范围内）

| 功能 | 说明 |
|---|---|
| 每日时政材料 | 首页 + 每日日报 + 周报（核心内容） |
| 搜索 | 站内检索每日材料 |
| 收藏 | 划线摘录 + 原文收藏 |
| 划线 AI 解释 | 划线 → DeepSeek 解释/追问 |
| 每日一练 | 每天 5~30 题客观题 + 即时反馈 |

### 当时砍掉的功能

| 功能 | 砍掉理由 |
|---|---|
| 登录/注册/找回密码/改密码 | 当时认为个人工具可使用匿名设备标识 |
| 后台管理（admin-site） | 内容审核走 GitHub 或极简本地脚本 |
| 邮件订阅 + 验证码中转 | 当时无账号体系 |
| 地区偏好、自定义文章 | 边缘功能，砍掉聚焦 |
| 考点卡片/错题本（间隔复习） | 与"每日一练"合并为最小版本，暂不做间隔算法 |

## 后果

- **好**：API 从 24 个端点降到约 6~8 个，重构量和测试量大幅下降。
- **代价**：换设备/清缓存后个人数据不同步（匿名标识）；若要跨设备同步，后续可加"单密码单用户"。

## 当前状态

该 ADR 的账号和邮件部分已被后续产品决策取代。当前规则为：

- QQ 邮箱验证码登录是 MVP 功能。
- 每日摘要订阅是 MVP 功能。
- 当前没有真实生产用户，不需要旧用户名账号迁移。
- 当前有效范围以 `docs/product/mvp-scope.md` 为准。
