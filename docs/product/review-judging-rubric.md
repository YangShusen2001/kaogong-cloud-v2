# 审核判定黄金标准（Review Judging Rubric）

> 「审核 Agent」`judge_item` 的评分维度与 verdict 映射。本文档是判定标准的唯一权威，`review_agent.py` 的 system prompt 以此为准。

## 定位

面向公务员 / 事业单位 / 申论考生，聚合**可信官方来源**的时政内容。审核 Agent 的目标是：把「该不该收、标题摘要好不好、AI 产出靠不靠谱」显式化，替代人工逐条判断。

## 评分维度（每篇 0–100 分）

### 1. 相关性（30 分，权重最高）——该不该收

- **应该收**：官方时政、政策法规、会议讲话、评论解读、申论素材、社会治理案例、民生政策、宏观经济、乡村振兴、科技创新、法治建设等。
- **不该收**：广告/软文、娱乐八卦、体育、纯商业推广、无关生活资讯、招聘、重复转载灌水、页面错误/登录跳转页。
- **边界**：来源是官媒，但单篇是生活服务类（如"本周天气"）→ 判低相关。

### 2. 标题质量（20 分）

- 去掉来源前缀（如"南方网评｜""【好评中国】"可只保留主体）。
- 无乱码、无 HTML 残留、无「…」截断、长度合理（建议 ≤ 30 字）。
- 准确反映正文主旨，不标题党。

### 3. 摘要质量（20 分）

- 长度 80–120 字（允许 60–150）。
- 概括正文主旨，**不添加原文没有的事实 / 数字 / 人物 / 结论**。
- 语言通顺、无机器味、无"本文讲述了""这篇文章介绍了"等套话。

### 4. AI 标注质量（20 分）

- **类型正确**：`viewpoint` = 明确判断/立场/价值取向/结论；`exam_point` = 政策措施/问题原因/治理方法/对策表达；`term` = 政策概念/治理术语/专业名词/新提法。
- **数量合理**：`viewpoint` 2–5、`exam_point` 3–8、`term` 1–5（硬上限 5/8/5，超上限由质量门禁记录）。
- **定位准确**：标注文本必须能在原文定位（质量门禁已校验偏移），此处判"标得对不对、有没有乱标/张冠李戴"。
- **术语释义**：30–80 字、准确、不跑题、不伪造。

### 5. 原文完整性（10 分）

- 正文非空、段落完整、无大面积截断。
- `aiStatus=error`：标注缺失但原文可发布（降级），不因缺标注判低分。

## verdict 映射

| verdict | 触发条件 | Agent 后续动作（Phase 2+） |
|---|---|---|
| `keep` | 相关性高 + 标题/摘要达标（score ≥ 80） | 不动 |
| `rewrite` | 相关性尚可，但标题/摘要不合格 | 给 `newTitle` / `newSummary` |
| `drop` | 相关性低 / 明显噪声 | 标记 excluded + `reason` |
| `rerun` | `aiStatus=error` 且原文可读 | 补跑 AI |

## 输出协议（judge_item 结构化返回）

```json
{
  "score": 85,
  "verdict": "keep",
  "reason": "官方政策解读，标题规范，摘要 98 字且准确概括，标注定位正确",
  "newTitle": "",
  "newSummary": ""
}
```

- `verdict=rewrite` 时 `newTitle` / `newSummary` 必填其一。
- `verdict=drop` 时 `reason` 必须说明"为何不该收"。
- `verdict=rerun` 时 `reason` 说明"补跑 AI 的原因"。

## 判定原则（红线）

- 不确定就不硬判：拿不准的项返回 `verdict=keep` 并在 `reason` 注明"低置信"，交给 `needsHuman`，绝不猜测删除。
- 不删除"可能是重要时政"的内容——删除是单向高风险动作，宁漏勿错。
- 每次判定都给 `reason`，可审计、可回看。
