# 用户流程

## 浏览首页

```text
打开首页
  -> 查看文章标题、来源、分类和 AI 概括
  -> 点击标题或卡片
  -> 进入阅读页面
```

## 阅读文章

```text
进入阅读页
  -> 默认显示原文模式
  -> 切换到 AI 标注模式
  -> 查看观点句、申论考点和政策术语
  -> 鼠标悬停政策术语查看 30-80 字释义
  -> 移开鼠标后释义消失
  -> 点击官方原文链接查看来源页面
```

## QQ 邮箱登录

```text
输入 @qq.com 邮箱
  -> 请求验证码
  -> 输入验证码
  -> 验证成功后创建或登录账号
  -> 设置安全 Session Cookie
```

验证码请求不得泄露邮箱是否已注册。

## 用户标注

```text
选中文本
  -> 选择荧光笔、下划线或注释
  -> 保存到用户标注数据
  -> 刷新后按段落偏移恢复
```

用户标注和 AI 标注互不覆盖、互不删除。

## 每日摘要订阅

```text
验证 QQ 邮箱
  -> 主动开启每日摘要订阅
  -> 每日报告发布后创建投递任务
  -> 邮件服务分批发送
  -> 记录成功、失败和重试状态
```
